An agent will clear seventy percent of this file in seconds and be confidently wrong somewhere in the tail. That is why this is still done by hand — not because it is difficult, but because nobody can bound the downside. [[slnc 380]] So we did not try to build an agent that is never wrong. We built a proposer that is allowed to be wrong, and a small gate that is only allowed to say no. [[slnc 380]] Read the wrong-payment column. Every gated row is zero, no matter how bad the proposer is. That is the claim. The gate is a property of the system, not of the agent behind it.
